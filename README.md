### 📌 Final Year Project (FYP)

**Detecting Source Code Vulnerabilities in C/C++ using Graph Neural Networks (GNNs)**  
- Developed a deep learning model leveraging **Graph Neural Networks** to identify potential vulnerabilities in C/C++ source code.  
- Constructed **abstract syntax trees (ASTs)** and **control flow graphs (CFGs)** to represent source code as graphs.  
- Trained and evaluated GNN-based models for classification of vulnerable vs. safe code snippets.  
- Achieved significant accuracy in detecting common vulnerabilities, contributing to **secure software development practices**.
